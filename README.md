# CCreator Tester — versões de teste

O **CCreator Tester** é o EV Content Creator no **canal de testes**: cada
atualização nova chega aqui **antes**, para ser testada sem mexer no app
oficial. Depois de aprovada, a mesma versão vai para o
[app oficial](https://github.com/EVArthurDricarr/ev-content-creator-releases).

Este repositório guarda só as **versões de teste**; o código fica em
repositório privado.

## É separado do app oficial

- Instala **ao lado** do EV Content Creator, com nome, ícone (o selo laranja
  "T") e pasta próprios.
- Recentes, preferências e salvamento automático são **dele**: nada do que
  você faz no Tester aparece no oficial, e vice-versa.
- O duplo clique num arquivo `.create` continua abrindo o **oficial**. No
  Tester, abra pelo **Abrir** ou arrastando o arquivo para a janela.
- A faixa do topo mostra a etiqueta laranja **Tester**.

## Baixar e instalar (só na primeira vez)

1. Abra **[Releases › a versão mais recente](https://github.com/EVArthurDricarr/ev-content-creator-testes/releases/latest)**
   e baixe o arquivo `CCreator-Tester-…-instalador.exe`.
2. Dê dois cliques no instalador. Se o Windows mostrar **"O Windows protegeu
   o computador"**, clique em **Mais informações** e depois em **Executar
   assim mesmo** (aparece com todo programa sem certificado pago de
   assinatura).
3. Clique em **Instalar**.

## Atualizar

**O Tester faz sozinho**, como o oficial: baixa a versão de teste nova em
segundo plano e mostra o botão laranja **Atualizar app**.

## Um cuidado

O Tester e o oficial abrem os mesmos arquivos `.create`. Se uma versão de
teste um dia mudar o formato do arquivo, o oficial avisa que o arquivo é de
uma versão mais nova até ser atualizado — ele não estraga nada.
